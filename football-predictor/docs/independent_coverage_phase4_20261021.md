# 独立模型覆盖扩展第四阶段（2026-10-21）

## 欧冠此前处于什么状态

欧冠已经纳入赛程、官方赔率分析和市场基准，但此前没有已验证的欧冠独立模型。现有国内联赛模型的训练域不能因球队参加欧冠而自动扩展：跨联赛实力、赛制、参赛球队变化、稳定身份映射都需要验证。本阶段已真正训练第一版欧冠独立研究基线，尚未启用正式路由。

四类候选均保存胜平负、净胜球九档（两端为≤-4/≥4）、总进球八档（0—6/7+）完整概率。测试模型参数和全历史重拟合候选分别保存，不混用。

英冠、日职及日乙使用纯历史球队攻防状态的共享形式泊松模型，分联赛拟合。欧冠使用稳定提供商球队ID、欧冠历史比分拟合带正则的球队攻防模型，不使用赔率，不假称已经实现国内联赛与欧冠强度联合模型。

英冠与日职训练截至2023年、2024年校准、2025年起留出；日乙2022年训练、2023年校准、2024年测试。欧冠2023/24训练、2024/25校准、2025/26测试。温度只由校准集选择，不根据测试结果调参。

## 验证与限制

英冠模型减市场的平均 Log Loss 为+0.016218，按周分块自助法95%区间[+0.002781,+0.030395]；日职为+0.018578，区间[-0.000295,+0.037692]。正值表示模型误差较大。市场为同场历史收盘均值去水，不是与当前体彩同步的报价；这些结果不用于宣称真实投注收益。

欧冠每队须在初始训练期至少出现5次，因而校准仅61场、另124场跳过；测试仅38场、另148场跳过。其0.943434好于训练期固定频率基准1.027648，但没有同期市场赔率对照，不能据此认为优于市场。样本偏向历史覆盖较充分的球队，不能代表所有欧冠比赛。跨联赛国内实力、阵容、xG尚未加入；新赛季和稳定身份映射也尚需补齐。

日乙免费接口允许2022—2024年，明确拒绝2026年；最近历史是2024-12-07，距当前683天。禁止用该旧状态预测当前日乙。欧冠免费账号取得2023—2025赛季，2022年被拒绝后停止，不新增付费订阅。

原始响应归档并计算SHA256。欧冠仅接受FINISHED、REGULAR、正确赛季、比赛日期早于截止日、整数有效比分，拒绝重复赛事ID；加时比赛全部排除，没有把加时后的全场比分当90分钟比分。严格解析重放与494条原标签完全一致。

新增标签测试及既有模型测试共13项通过。四类已保存的测试模型各重放20场，胜平负、净胜球和总进球概率均与原测试产物一致。

## 上线边界及接续工作

本阶段为独立研究产物，未改现有生产配置、控制器路由、正式预算、冻结票或历史预测，未重排总控。不能宣称今天13场已经因此获得独立覆盖。研究配置中所有production_enabled与live_routing_enabled均为false。

下一步按顺序推进：

1. 补欧冠2026/27及日乙当前有效赛果；通过稳定球队ID/人工核验别名建立当前赛事映射，禁止模糊匹配直接下注。
2. 英冠、日职候选先进入独立研究队列的赛前冻结与赛后评分；完成接口、时效和同场市场对照验证后再允许自动路由。本阶段未完成该路由接入。
3. 欧冠增加国内联赛球队实力作为跨联赛输入，并保留本次欧冠纯比分基线；以未参与选择的新时间段验证增量，补历史或前瞻市场对照。不要把纯独立模型与盘口增强模型混在一起。
4. 日乙数据新鲜度不合格时继续明确跳过；有官方市场报价可做市场观察，不冒充独立模型。
