# 独立预测及概率校准提升

2026-10-12用户授权研究提升。所有方案继续仅用虚拟资金；当前生产基准不因研究启动自动晋级。

首轮范围：优先从现有欧洲七联赛历史中选择映射和比分覆盖最好的联赛；不新增收费订阅。重新运行赛前信息覆盖审计，核验已有数据能否按唯一比赛ID、球队别名、开赛时间和观测时间连接。原始赛前快照不可回写，缺失不得填零。

研究实现顺序：

1. 整理纯球队训练表，排除全部赔率字段；历史进球、主客场、对手强度和时间衰减为第一版输入。仅用比赛发生前已知结果构建特征。
2. 输出双方进球联合分布，并汇总胜平负及净胜球九档概率。标注尾部截断或聚合处理。伤停、阵容、xG、负荷及旅行仅在来源、许可和时间通过验证后逐项评估。
3. 分别冻结纯球队模型、同时间市场基线、融合模型，记录版本、截止时间和全部比赛；无方案场次也保留预测。
4. 按时间划分训练、校准、测试；内层选择校准器，外层只评估。报告胜平负与九档净胜球的可靠性曲线、Brier、Log Loss、分联赛及让球方向表现、样本数和不确定区间。校准器不得接触测试结果。
5. 预测验证与票结构收益分开；比赛为独立统计单位。以相同比赛、预测时间和预算比较，沿用已有晋级闸门，不因单日ROI或票数增加晋级。

用户配合项：告知已有API-Football、SportMonks或其他合法球队数据账号、订阅范围；如新增收费服务有必要，先提交具体缺口、覆盖与费用再请求批准。密钥只通过本地环境变量或安全配置提供，不在聊天中明文发送。未提供账号时先使用现有合法数据推进第一版。

授权不包括购买、升级套餐、真实投注或Supabase同步。持续总控仍绑定现有唯一心跳；本文件是研究计划，不表示独立模型已经训练完成。
