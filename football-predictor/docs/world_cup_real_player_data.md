# 世界杯真实球员数据接入

## 已接入来源

首批真实数据使用 StatsBomb Open Data：

- 来源：https://github.com/statsbomb/open-data
- 覆盖赛事：2018、2022 男子世界杯
- 比赛数：128
- 球员数：1,328
- 球员比赛记录：6,130
- 球员身份解析率：100%
- 每队 11 名首发覆盖率：100%
- 出场分钟覆盖率：100%

数据缓存位于 `data/external/statsbomb-open-data`，转换结果位于
`data/player_level/statsbomb_world_cups`。

## 已获得的真实字段

- StatsBomb 球员 ID 和姓名
- 国家队
- 比赛日期和对手
- 首发或替补
- 场上位置
- 出场时间
- 当前比赛名单

这些数据已经转换到项目的统一球员数据契约，并生成 128 场赛前阵容特征。

## 当前缺失

StatsBomb 首批开放数据没有覆盖：

- 2026 世界杯实时首发
- 2026 赛前伤病、停赛和存疑状态
- 球员俱乐部归属快照
- 近期俱乐部出场分钟
- 近期俱乐部进球、助攻、xG 和 xA
- 教练和战术风格

因此目前只能把真实数据用于历史阵容连续性研究，不能用于修改当前 2026 正式预测。

## 覆盖率决策

| 数据层 | 历史 2018/2022 | 当前 2026 |
| --- | ---: | ---: |
| 球员身份 | 100% | 0% |
| 11 人首发 | 100% | 0% |
| 出场分钟 | 100% | 0% |
| 伤停状态 | 0% | 0% |
| 俱乐部近期表现 | 0% | 0% |

模型晋级条件尚未满足，因此 `model_promotion=false`。

## 使用命令

下载并转换开放数据：

```powershell
.\.venv\Scripts\python.exe scripts\import_statsbomb_world_cups.py --download true
```

仅重新转换本地缓存：

```powershell
.\.venv\Scripts\python.exe scripts\import_statsbomb_world_cups.py --download false
```

## 下一数据源需求

后续实时来源至少需要提供：

1. 2026 世界杯官方名单和确认首发。
2. 伤病、停赛和出战存疑状态，并带更新时间和来源。
3. 球员当前俱乐部及最近 90 天逐场分钟。
4. 球员近期进球、助攻、xG 和 xA。
5. 教练、阵型和换人信息。

商业数据源可以提供更完整覆盖；若使用免费来源，需要分别接入官方名单、比赛阵容和俱乐部比赛数据，并维护跨来源球员身份映射。
