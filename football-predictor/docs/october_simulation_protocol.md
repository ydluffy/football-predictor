# 10月预测与宽松模拟研究协议

2026-10-12独立预测对照扩展见docs/independent_comparison_controller.md：原宽松研究之外，单独冻结市场/独立/固定融合的共同覆盖对照；不可把独立对照金额混入原正式或固定赔率影子台账。

2026-10-02 用户授权：当前只收集数据、验证预测和研究方案，不动用真实资金；扩大方案数量和结构，验证后再选择重点策略。本协议优先于旧文档中研究方案沿用正式筛选条件的要求。

## 双轨规则

旧正式模拟仍是冻结的基准：原52%/1.85筛选、模型辅助条件及每天数量规则保留，用于比较。新增宽松研究不设52%概率、1.85价格、正期望收益、外盘完整或每天两组门槛；无模型可用时允许市场基线实验，但必须标注来源，不能宣称独立预测优势。零共享只作结构研究，不晋升生产。所有金额都是虚拟数，不执行真实投注。

研究脚本覆盖批次全部场次，不再默认只分析前三场。每场生成理论单场观察；每类最多12个二串组合，并比较防冷双选、强方向加双选、前三场三串、前四场六组二串和四串。排序固定、赛前冻结，不按赛后结果挑选。限制组合枚举是为防止同场重复票淹没统计，不限制当天批次数。

单关资格未确认时标记 `unverified_theoretical`，不能称可出票。净胜球让平分支是研究假设，不是认为每场都恰好打到盘口。比分、总进球、半全场缺少完整官方赔率或相应预测时，保持方向观察，不编造概率、报价或收益；完整的用户赛前方案可按既有外部结构协议另行登记。

## 逐场分析

先说明球队实力、近期表现、赛程负荷、阵容伤停与缺失项，再展示模型的净胜球九档分布（客胜4+、3、2、1；平；主胜1、2、3、4+），映射普通胜负和体彩整数让球。输出须注明概率来源和模型版本；分布缺失显示不可用，不从三项让球概率反推九档分布。现有净胜球模型使用市场特征，不称其为完全独立于市场的球队实力模型。

模型可用时用 `scripts/predict_sporttery_handicap.py` 或 v2旁路输出CSV，新增字段 `prediction_at` 和 `margin_probability_*`。v3继续研究，不因本协议自动晋升。说明模型与市场的分歧及不确定性，不用一句参考比分替代概率分布。

## 每批执行

官方刷新、终版门禁、原正式策略和编排验证后，在同一批硬锁之前执行：

```powershell
.\.venv\Scripts\python.exe scripts/run_october_research.py freeze --sales-day YYYY-MM-DD --batch-id HHMM_001_009 --market-csv <本批官方CSV> --gate-json <本批READY门禁JSON> --handicap-model-csv <本批模型CSV>
```

没有安全模型时省略模型CSV，不能因此跳过整个研究层。命令按真实当前北京时间冻结，核验批次覆盖、开赛、硬锁、官方抓取时间、门禁时效与市场来源；不提供历史时间覆盖参数。国庆停赛期不运行此命令，不补造9月前瞻方案。

产物在 `artifacts/data/october_research/`：同批不可变JSON和完整Markdown。来源CSV、门禁、模型文件保留SHA-256。相同批次相同输入幂等返回，输入改变拒绝重写。正式台账和旧影子台账不写入该研究记录。

次日官方90分钟赛果完成后，对前一销售日及更早未结算快照逐一执行：

```powershell
.\.venv\Scripts\python.exe scripts/run_october_research.py settle --snapshot <冻结JSON> --results-csv <官方赛果CSV>
```

赛果必须按编号、主客队和实际北京时间开赛日期唯一匹配；缺失/歧义/未完场保留pending。结算使用赛前冻结的赔率；结果摘要按赛果文件哈希保存版本，不重选方案。输出理论返奖、每类命中与ROI；复盘正文逐腿展示赛果、断票与盈亏。

结算后运行 `.\.venv\Scripts\python.exe scripts/run_october_research.py summarize`。汇总自动选择每份冻结快照的最新复盘版本，输出每类方案数、待结算数、有效销售日、独立赛事、ROI、完整批次最大回撤，以及共同完整批次按每类12元虚拟预算归一化的ROI。不同选场仍不是纯结构对照，报告明确说明。完整九档净胜球概率自动结算Brier和Log Loss，汇总同场同模型只取最新冻结预测一次；缺失或无效分布不评分。球队定性证据与逐腿解释由总控在复盘正文补充；不自动挑选策略。

## 评估与重点研究

优先比较净胜球导向让球、普通胜负基线、强方向加双选和同输入六组二串；高赔率和比分票仅独立探索。用户旧票是回顾性选中样本，只学习结构，不计前瞻收益。

周/月回顾从同一批冻结记录及最新已核验赛果汇总。每类同时报票数、有效销售日、独立场次、投入、返奖、ROI、最大回撤、单日极端收益占比、重叠场次和待结算数；不把同场几十张变体算几十次独立预测。不同结构在相同选场及相同有效日期上比较，并另外按相同虚拟预算归一化，不能用总返奖大小决定优胜。

模型有完整概率时统计胜负/净胜球概率误差、Brier和Log Loss；市场概率与模型概率分组。缺概率或精确分布的记录不能进入相应评分。30个有效销售日做第一次描述性复核，样本与风险闸门未过不确定重点生产策略，不自动提高预算或启用新模型。

本协议不新建自动化，不改唯一心跳ID、目标或下一唤醒；仍为local、无工作树。外盘额度重置仅为用户报告，首次恢复前必须实时验证。
