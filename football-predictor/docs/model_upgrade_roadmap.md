# 足球预测模型分赛事升级路线

## 当前状态（2026-08-09）

第一阶段基础设施已经落地：

- `config/competitions.json`：统一赛事 ID、赛制、赛季格式、模型组和历史覆盖状态。
- `data/mappings/team_aliases.json`：跨数据源球队别名的首批映射。
- `scripts/audit_competition_coverage.py`：按赛事审计赛季数、赛果、赔率和模型覆盖。
- `src/features/season_context_features.py`：无未来泄漏的赛季进度和赛季阶段候选特征。
- 体彩扫描输出赛事 ID、球队标准名、历史模型覆盖和安全降级路由。

`v7` 已完成四个赛季滚动留出评估，但所有留出赛季均弱于市场概率基线，因此状态为 `rejected`，未替换生产模型。

## 模型路由原则

1. 世界杯可以使用已存在的世界杯专项模型。
2. 欧洲杯和其他国家队赛事使用国家队骨干模型，但必须补赛事校准。
3. 英格兰 E0-E3/EC 有历史训练数据，但联赛校准仍是候选能力。
4. 西甲、德甲、法甲、意甲、日职联等在补齐历史训练数据前，只能使用市场锚定安全降级。
5. 未识别赛事禁止静默套用任何俱乐部历史模型。

## 下一批数据工作

按优先级补齐：西甲、德甲、法甲、意甲、日职联、日职乙、韩职。每项联赛目标为至少五个完整赛季的赛果和赛程，以及尽可能三至五个赛季的赛前 1X2、让球和总进球赔率。

国内杯赛和洲际赛事即使暂时没有完整赔率，也必须进入全赛事赛程日历，用于休息、连续客场、加时和轮换压力计算。

## 后续候选特征

- 赛前积分榜快照与剩余轮次
- 争冠、欧战、升级、保级积分压力
- 升班马和新赛季适应期
- 国内杯赛/洲际赛事前后赛程负荷
- 小组赛出线形势、淘汰赛首回合/次回合状态
- 旅行距离、时区和连续客场

这些特征必须带可用性标记；缺失时降级，不得用零值伪装成真实信息。

## 第二阶段数据与评估结果（2026-08-09）

- 已建立 `europe_extended` 候选数据集：英超、西甲、德甲、法甲、意甲、荷甲、葡超共 7 个联赛，覆盖 2020-21 至 2025-26 六个赛季。
- 原始 14,406 场中有 8 场缺少统一口径的 B365 赛前 1X2 开盘赔率，候选训练集保留 14,398 场；不混用不同赔率字段填补。
- 逐联赛滚动赛季留出只用于研究，评估脚本不会自动晋升或覆盖生产模型。
- `v1` 中意甲、荷甲、葡超达到“校准研究候选”条件；这不是生产晋升结论，下一步仍需配对 bootstrap、校准稳定性和影子运行。
- `v7` 在 7 个联赛均弱于同场市场隐含概率，继续保持拒绝状态。

## 东亚数据源策略

- 日职联：采用 OpenFootball 的 CC0 数据，首批覆盖 2019-2025；只进入赛程、赛果、赛季阶段、休息和赛程负荷上下文层。
- 日职联公开文件不含赛前赔率，因此输出强制标记 `model_training_eligible=false`，不得进入现有赔率模型训练集，也不得仅凭赛果数据生成投注方案。
- 本次实际导入 2,364 条：2019-2024 共 1,984 场赛果完整；2025 文件仅有 136/380 场赛果，另外 244 条是历史未决赛程占位。审计明确标记 2025 不完整，全部排除于赛果训练和当前赛程使用。
- K 联赛：官方数据门户对复制、存储和分发有限制。取得书面许可或找到许可证明确的替代源前，禁止自动抓取和落库。
- 所有东亚数据源由 `config/east_asia_data_sources.json` 统一声明许可、存储、自动下载和模型训练权限；导入器必须先过策略闸门。

## 下一研究批次

1. 对意甲、荷甲、葡超的 `v1` 候选做逐赛季配对 bootstrap 和概率校准稳定性检查。
2. 用影子模式记录预测概率，不直接改变现有投注方案逻辑。
3. 为日职联补充许可证明确的赛前赔率源后，另建 J1 独立候选模型；不得把欧洲联赛参数静默复用到 J1。
4. K 联赛保持 `permission_required`，授权问题解决前只保留接口占位和审计状态。

## 第三阶段校准研究结论（2026-08-10）

对意甲、荷甲、葡超 `v1` 候选执行 5,000 次同场配对 Bootstrap，并在每个滚动赛季留出中用更早赛季训练 Sigmoid 校准器：

- 意甲：校准后相对市场 Log Loss 为 -0.002346，95% CI [-0.007092, +0.002613]，模型胜出概率 83.22%。
- 荷甲：校准后相对市场 Log Loss 为 -0.000377，95% CI [-0.005813, +0.004942]，模型胜出概率 55.48%。
- 葡超：校准后相对市场 Log Loss 为 -0.000303，95% CI [-0.006846, +0.006408]，模型胜出概率 54.18%。

三项赛事的置信区间均跨过零，且胜出概率均未达到预设的 95% 闸门，因此全部标记为 `research_rejected`：

- 不创建影子模型配置；
- 不替换生产模型；
- 不改变投注方案生成逻辑；
- 下一研究方向改为市场残差建模、有效的新信息特征和更长样本验证，不能继续仅靠同一组赔率特征反复校准。

## 第四阶段市场残差研究（2026-08-10）

已实现以市场隐含概率为固定基线、只用非赔率上下文预测结果残差的研究模型。每个外层留出赛季的 Ridge 正则化和修正强度，仅使用更早的开发赛季与最近验证赛季选择；强度候选包含 0，表示没有可靠增益时严格退回市场概率。

两组特征均完成七联赛、四个滚动留出赛季和 5,000 次配对 Bootstrap：

- `v7`：近期进球、赛程负荷和赛季阶段，共 28 个非赔率上下文特征；七联赛平均 Log Loss 均未优于市场。
- `v8`：在 `v7` 基础上增加历史滚动射门、射正、角球和牌数，共 37 个非赔率上下文特征；仍无联赛通过统计闸门。
- `v8` 意甲相对市场 -0.000020，胜出概率 52.00%；葡超 -0.000184，胜出概率 56.86%，均接近随机且置信区间跨零。
- 英超 `v7/v8` 均出现统计显著退化，进一步说明现有上下文不能直接用于提高投注置信度。

结论：不创建影子配置，不改生产模型，不改变投注逻辑。下一阶段必须优先补齐当前数据集中不存在的赛前新增信息：确认阵容与关键球员缺阵、可用的赛前 xG/球队强度快照、跨赛事完整赛程负荷、旅行距离与时区，以及严格带时间戳的赔率变化。

## 第五阶段赛前新增信息数据层（2026-08-10）

- 建立 `config/prematch_data_sources.json`，统一声明来源许可和可使用的信号类型。
- 建立 `data/manual/prematch_intelligence.csv` 通用长表，以及阵容、伤停、赛前强度/xG、旅行、时区和跨赛事负荷字段契约。
- 强制执行 `observed_at <= analysis_at < kickoff_at`；开赛后补录、缺时间戳、来源未登记或许可不匹配的记录全部拒绝。
- 特征层输出数值和独立可用性标记，禁止用零值伪造信息完整。
- 覆盖审计确认：欧洲扩展历史候选集 14,398 场在七类赛前新增信息上均为零覆盖；现有外盘历史仅 123 行、66 个事件，其中 121 行早于开赛；世界杯专用数据资产不能视为联赛覆盖。
- 数据层已可用于今后的每日终版采集，但在达到两个完整赛季、每联赛至少 500 场双队覆盖以及时间/许可/映射通过率 98% 前，新增信息模型保持阻断。

## 第六阶段自动采集与持续积累（2026-08-10）

- `run_sporttery_sales_window_scan.py` 每次 preopen/confirm 运行后，自动把官方胜平负/让球和扩展玩法 CSV 复制到不可变快照仓库。
- `sporttery_snapshot_index.csv` 记录 snapshot ID、抓取时间、原文件、归档文件、SHA-256、行数、场次号及安全/不安全场次；重复运行相同快照保持幂等。
- 已用 2026-08-09 22:04 确认扫描完成回放：24 个场次中，013-024 共 12 场在抓取时尚未开赛，可进入赔率历史；001-012 共 12 场已过开赛时点，自动排除。
- 新增通用 API-Football 赛前导入器。外部 fixture 必须通过主客队标准名和开赛时间（默认误差不超过 15 分钟）唯一映射到体彩 `sales_day|match_number`，歧义和未匹配记录禁止写入。
- API-Football 阵容/伤停只有在配置有效凭据、完成唯一映射且 `observed_at` 早于开赛时，才进入验证数据。当前环境未配置 `API_FOOTBALL_KEY`，本地演练状态为 `skipped`、`write_performed=false`。
- 自动采集已经具备安全运行条件，但数据量仍未达到模型训练或影子运行门槛。

## 晋升闸门

- 使用滚动赛季留出，不使用随机切分。
- 与同场市场隐含概率比较 Log Loss、Brier 和校准误差。
- 至少两个近期留出赛季不弱于市场，且不能存在主要赛事灾难性退化。
- ROI 只作为二级指标；样本不足 300 个独立已结算方案时不得据此晋升。
- 候选先影子运行，再由月度回顾决定是否晋升。

## 第七阶段精确亚洲盘口研究（2026-08-10）

- 欧洲七联赛六赛季历史候选集包含 `AHh/AHCh` 及对应平均主客赔率，可用于外盘初盘、终盘和精确盘口研究。
- 新增逐 0.25 球盘口结算，四分之一盘拆分为两半注，保留全赢、半赢、走盘、半输和全输。
- 回测按精确盘口、联赛和赛季输出；平半、半球、一球、球半和两球均已形成超过 100 场的研究样本。
- 历史外盘不能替代历史体彩内盘。当前两套近期归档尚未形成足够的同场同时间配对，内外盘差值训练继续阻断。
- 本阶段仅建立研究基准，不修改生产模型、影子配置和投注逻辑。

## 第八阶段体彩整数让球候选模型（2026-08-10）

- 使用 14,392 场完整赛前外盘数据训练九档净胜球分布，再转换为体彩 `-2/-1/+1/+2` 的让胜、让平、让负概率。
- 特征只使用开盘亚洲盘、两侧赔率、1X2、大小球、联赛和赛季进度；收盘赔率不进入训练，避免早期预测泄漏。
- 2022-23 至 2025-26 四个滚动留出赛季共 9,523 场，转换为 38,092 个场景；所有场景仍以原比赛为聚类单位评估。
- 总体相对历史盘口条件基线 Log Loss 改善 `-0.003531`，同场聚类 95% CI 为 `[-0.005142, -0.001824]`。
- 最新 2025-26 留出中 `+1`、`+2` 场景轻微退化，因此最近两季稳定性硬闸门未通过，候选保持 `research_rejected`。
- 历史体彩 RQSPF 赔率尚未与外盘同场同时间对齐，无法验证实际价值和 ROI；不创建生产配置，不改变投注逻辑。

## 第九阶段 v2 影子候选与组合风险控制（2026-08-16）

- 新增 `sporttery_handicap_temporal_blend_v2_shadow`，采用扩展赛季留出和仅使用前一已知赛季的内层权重选择；`-2/-1` 最多使用 50% 候选权重，`+1/+2` 最多使用 25%，其余概率向历史盘口基线收缩。
- 9,523 场、38,092 个场景的回测中，相对基线 Log Loss 为 -0.002781，聚类 Bootstrap 95% 区间 [-0.003391, -0.002147]；最近两个留出赛季四档让球均未退化，状态为 `shadow_candidate`。
- 新增影子组合策略：拒绝纯市场概率、默认最多 2 串、赔率上限 4.00、概率不确定性折减、单场/联赛/总仓位硬上限及 0.15 倍凯利。
- 当前真实候选仍只有市场去水概率，因此组合影子审计选中 0 个方案；不得为了产生方案绕过独立模型概率要求。
- 生产晋级继续阻断，直到历史体彩赔率完成同场同时间对齐，并积累至少 300 个独立已结算影子方案，同时通过校准、收益风险和最大回撤闸门。
- 详细设计、命令和日常影子流程见 `docs/shadow_v2_upgrade.md`。
