这份文档用于在不同智能体之间做任务交接。它不是“长期项目说明书”，而是每次切换执行者时都可以快速更新的一页记录。

适用场景：

- 你把任务从 Trae Work 转交给 Codex
- 你把任务从本地 Codex 转给 Coze 云端电脑
- 你想让 Claude Code / OpenClaw / Hermes 接手一个局部任务

## 使用原则

1. 只写对下一位执行者真正有用的信息
2. 不重复抄整份 README
3. 明确“当前状态、下一步、禁止事项”
4. 交接时优先贴文件路径、命令和分支，而不是长篇聊天记录

## 哪些内容应该写进交接

适合写进来的内容：

- 当前任务到底在做什么
- 当前所在分支
- 已修改的关键文件
- 还缺什么
- 下一位必须先看的路径
- 有风险的操作

## 哪些内容不要写进交接

不建议写：

- 大段重复背景介绍
- 和当前任务无关的长期历史
- 复制整份聊天记录
- 只写“继续开发”这种没有信息量的话

## 推荐做法

每次重要切换前，至少补这 5 项：

1. 当前分支
2. 当前目标
3. 已完成
4. 未完成
5. 禁止事项

如果任务涉及 Git、数据库、自动化调度、Colab 或正式生产链路，交接文档必须更新后再切换执行者。
